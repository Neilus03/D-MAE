
| Family | Algorithms in the course | Policy type | On vs off policy | Main “tricks/keywords” |
|---|---|---|---|---|
| Planning (known model) | policy evaluation, **policy iteration**, **value iteration**; (POMDP) **belief-MDP** idea, **PBVI/PBPI** | implicit (greedy from \(V/Q\)) or explicit \(\pi\) | not an issue (no sampling required) | **Bellman** expectation vs optimality backups; solve linear system \((I-\gamma P^\pi)^{-1}r^\pi\); POMDP via beliefs, point-based approximation |
| Model-based RL | **MPC**, planning-horizon rollouts; **random shooting**, **CEM**; **PILCO**, **PETS**, Bayesian RSSM-style latent models; confidence bounds / optimistic planning | usually implicit from planning (or learned if you also learn a policy) | typically you can reuse data off-policy | learned dynamics; **compounding error**; **uncertainty** (epistemic/aleatoric); ensembles/GPs; optimism / confidence sets; replan every step (MPC) |
| Value-based model-free | **TD-learning (V)**, **SARSA**, **Q-learning**, **optimistic Q-learning** (Rmax-style optimism); **approximate Q-learning** (linear/NN); **DQN**, **DDQN** (and “Double Q-learning” idea) | implicit greedy from \(Q\) (or \(\varepsilon\)-greedy during training) | TD and SARSA are **on-policy**; Q-learning, approx Q, DQN, DDQN are **off-policy** | **bootstrapping** (low variance, biased); SARSA uses taken \(a'\) (often safer); Q-learning uses \(\max_{a'}\) (optimal but **maximization bias**); function approximation can be unstable due to **moving targets**; DQN uses **replay** + **target net**; DDQN reduces overestimation by decoupling argmax vs evaluation |
| Policy gradient | **REINFORCE**, policy gradient theorem | stochastic policy | on-policy | Monte Carlo returns \(G_t\); **high variance**; **baselines** / advantage to reduce variance; \(\nabla_\theta \log \pi_\theta(a\mid s)\) pattern |
| Actor-critic (on-policy) | actor-critic (generic), **A2C**, **A3C**, **GAE/GAAC**, **TRPO**, **PPO** | stochastic policy | on-policy | critic gives baseline; **advantage estimates**; GAE bias/variance tradeoff; TRPO uses **KL trust region**; PPO uses **clipping** (or KL penalty variant) to limit destructive updates |
| Actor-critic (off-policy, continuous) | actor-critic (generic), **DDPG**, **TD3**, **SVG** | often deterministic (DDPG/TD3), stochastic possible (SVG) | off-policy | replay + target nets; deterministic policy gradient; TD3 fixes overestimation with **twin critics (min)** + **delayed actor** + target smoothing; SVG uses reparameterizable stochastic policy gradients |
| Max-entropy RL | **SAC**, **MPO** | stochastic policy | off-policy | maximize reward + **entropy** (SAC); soft value targets; stable continuous control; MPO uses EM-style update, **KL constraints** between old and new policy; tends to be robust to hyperparameters |
| RLHF | reward model + **RLHF** policy optimization (often **PPO-based**) + KL regularization | stochastic policy | mostly on-policy for PPO step (reward model training can use logged data) | preference data \(\rightarrow\) **reward model**; optimize policy with **KL penalty** to a reference policy; “do not drift too far” regularization |
